01 / Direction

Brand direction

The ideas behind the Elsewhere identity.

Official identity

Brand name

Elsewhere

Official slogan

Archetypes

Sage + Creator

Visual direction

Postmodernism

Young creatives

05 / Spacing

Space and layout

Consistent spacing gives the website room to breathe.

Space 1 0.5rem
Space 2 1rem
Space 3 1.5rem
Space 4 2rem
Space 5 3rem
Space 6 4rem

Smaller spacing helps group related information. Larger spacing separates sections and creates visual breathing room.

06 / Buttons

Buttons and actions

Buttons should make the next step clear.

Primary action ↗ Secondary action ↗

Sage green is used for the main action, with a forest-green hover state. The secondary button uses a lighter treatment so it does not compete for attention.

07 / Voice

Brand voice

The words should feel as intentional as the visual design.

How Elsewhere communicates

Use clear, conversational language. Keep messages direct and make room for individuality and self-expression.

Example message

Less ordinary. More you.

Avoid making unsupported claims about product materials, manufacturing, sustainability, fit, or delivery.

Elsewhere uses a shared set of colors, typography, and spacing across its pages. Keeping these choices consistent helps the website feel like one brand.
